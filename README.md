# my-voice

一个中文写作 skill：直接、口语、具体，减少套话，保留事实与边界。

适用于文章、帖子、说明和提示词改写。文章保持完整段落；短回复可以更简洁。不会为了口语化硬塞口头禅、粗口或虚构经历。

## 使用

将本仓库的 SKILL.md 和 agents 目录放入你的 skills/my-voice 目录。

示例：

> 用 $my-voice 改写下面的文章，保留原意和必要细节。

> 用 $my-voice 写一段产品使用说明，直接讲操作和限制。

当前任务指定的语气、格式和篇幅优先于默认规则。

## 公开内容

此仓库仅包含抽象写作规则和使用说明，不提供原始聊天、真实对话例句、个人统计、身份资料或私人校准记录。个性化素材应由使用者自行保管，不提交到公开仓库。
